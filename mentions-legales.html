Hébergement

Le site est un ensemble de fichiers statiques (HTML, CSS, JavaScript, images, une vidéo). Il ne comporte ni base de données, ni espace membre, ni formulaire traité par un serveur. Il est destiné à être publié, par exemple, par GitHub Pages (GitHub Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, États-Unis), ou sur tout hébergeur statique équivalent.

Données personnelles

Ce site ne collecte aucune donnée personnelle. Il n'utilise aucun témoin de connexion (cookie), aucun traceur publicitaire, aucun outil de mesure d'audience tiers, et ne charge aucun script depuis un domaine extérieur. Il fonctionne entièrement à partir de ses propres fichiers.

  • Le formulaire de la page Contact ne transmet rien à un serveur : il prépare un courriel dans votre logiciel de messagerie, que vous voyez et envoyez vous-même.
  • Aucun compte n'est nécessaire pour télécharger un logiciel.
  • Les fichiers téléchargés le sont directement, sans inscription ni suivi nominatif de la part du site.

Dans les logiciels eux-mêmes (Stockia, D.D- Spirity), les données que vous saisissez — ventes, stock, élèves, présences, personnel — sont enregistrées sur votre poste, dans un fichier local. ModEric Software n'y a pas accès et ne les reçoit pas. Vous pouvez les copier, les sauvegarder et les emporter.

Si vous nous écrivez par courriel, votre message et votre adresse servent uniquement à vous répondre. Vous pouvez demander leur suppression à contact@mod-eric.com.

Intégrité des fichiers publiés

Chaque fichier de logiciel publié sur ce site est accompagné de sa taille et de son empreinte SHA-256. Cette empreinte permet de vérifier que le programme reçu est identique à celui que nous avons fabriqué. Sous Windows :

certutil -hashfile "C:\chemin\fichier.exe" SHA256

Les exécutables ne sont pas signés par un certificat commercial à ce jour : Windows peut afficher un avertissement SmartScreen à l'installation. La marche à suivre est décrite dans la notice livrée avec le logiciel.
