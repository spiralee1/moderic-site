Comment se passe une installation

Vous téléchargez, nous restons joignables.

  • 1 · Vous téléchargez le fichierSur cette page. Aucun compte à créer, aucun courriel à donner pour obtenir un programme.
  • 2 · Vous vérifiez l'empreinteLa valeur SHA-256 publiée avec le fichier permet de contrôler qu'il est intact.
  • 3 · Vous installez, nous accompagnonsLa notice est dans le paquet. Pour une mise en service avec vos données, écrivez-nous : nous convenons d'un moment.
  • 4 · Les mises à jour remplacent, elles n'effacent pasUne nouvelle version s'installe par-dessus la précédente : vos ventes, vos élèves et vos réglages restent en place.
